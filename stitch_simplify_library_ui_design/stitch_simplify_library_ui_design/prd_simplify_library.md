# PRD: Simplify Library
Tagline: "Sederhanakan narasi, percepat pemahaman."

## 1. Product Overview
Simplify Library adalah platform baca digital yang mengubah buku-buku yang sudah ada — terutama buku hukum — menjadi ringkasan terstruktur (Buku → Bab → Sub-bab) yang mudah dan cepat dipahami, tersedia gratis untuk siapa saja, khususnya mahasiswa hukum.

### Tipe Pengguna:
- **Admin/Editor**: Menyederhanakan buku, mengatur struktur Bab/Sub-bab, kategori, publikasi.
- **Pembaca (Publik)**: Membaca ringkasan buku secara gratis tanpa perlu mendaftar/login.

### Fitur Utama MVP:
1. **Landing Page (Hero + Featured/Kategori Populer)**
2. **Katalog Buku**: Search, Filter Kategori (Hukum Pidana, Perdata, Tata Negara, dll.), Toggle Grid/List
3. **Halaman Detail Buku**: Metadata, Sinopsis, Daftar Bab & Sub-bab
4. **Halaman Baca Bab/Sub-bab**: Reader view terstruktur, navigasi next/prev bab, tipografi baca nyaman
5. **Dashboard Admin**: Login, CRUD Buku, Block-based Editor (AFFiNE/BlockSuite style), Hierarchy Manager, Status Draft/Publish
